# Optional official 3D/CAD/AR discovery

Dell publishes interactive R730 service **3D Guides**, including the hard-drive backplane and PSU workflows. Public pages discovered:

- https://www.dell.com/support/product-details/en-us/product/poweredge-r730/resources/3dguides
- https://www.dell.com/support/resources/en-ph/3dviewer/ic14000r730001601a/how-to-replace-the-hard-drive-backplane-on-a-poweredge-r730
- https://www.dell.com/support/resources/en-bm/3dviewer/ic14000r730002401a/how-to-replace-the-power-supply-unit-psu-on-a-poweredge-r730

The interactive pages identify the R730 but do not publicly advertise a downloadable GLB, glTF, STEP, OBJ or FBX. Browser and direct requests from this environment consistently received HTTP 403 from Dell/Akamai for the viewer route. Search across Dell media, support downloads, CAD/BIM portals and common 3D keywords found no exact downloadable official R730 **8LFF installed-configuration** model. The returned access-denied response and headers are preserved beside this file; no unofficial or SFF mesh is represented as official.

The required newly built standard and web GLBs remain independent deliverables under `model/`.
