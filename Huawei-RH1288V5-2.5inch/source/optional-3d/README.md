# Optional official/successor-official 3D source

`xfusion-1288hv5-viewer/` is an unchanged public resource capture from:

<https://support.xfusion.com/server-3d/res/server/1288hv5/index.html?lang=en>

Captured 2026-08-23. It contains the page, `tree.json`, public iV3D `obj0.bin` through `obj15.bin`, six JPEG atlases, and public runtime JS/CSS required to interpret the resource set. Checksums are in `xfusion-1288hv5-viewer/SHA256SUMS.txt`.

This is not a GLB, glTF, Wavefront OBJ, STEP, FBX or standard CAD file. The viewer default front is the incompatible 8SFF/DVD/VGA variant, so it is an optional geometry reference for the shared 708 mm 2.5-inch chassis, top, sides and conservative bottom fallback only. It is not copied into the newly constructed GLBs and does not replace the exact 10SFF source-locked build. No explicit redistribution license was displayed by the viewer.

No public exact official GLB, glTF, STEP, FBX or standard CAD download was found.
