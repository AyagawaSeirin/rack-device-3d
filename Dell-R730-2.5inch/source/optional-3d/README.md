Dell currently exposes official interactive R730 service 3D Guides, including exact-model procedures for the PSU, three risers, system cover, fan assembly, control panel and backplane. The public list and an example viewer are recorded in `../evidence.md`.

No direct public GLB, glTF, STEP, STP, OBJ, FBX or other raw model download was exposed by Dell search, product resources, manuals, media pages or the viewer URL. Browser and plain HTTP inspection of the interactive viewer returned Dell/Akamai HTTP 403 from this environment. The untouched response is preserved as:

- `dell-r730-psu-3dviewer.html`
- `dell-3dviewer-response-headers.txt`

Those files are evidence of the attempted official interactive path, not 3D assets. No unofficial model is stored here or represented as official.
