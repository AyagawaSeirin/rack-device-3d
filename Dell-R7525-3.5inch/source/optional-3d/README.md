# Optional official 3D/CAD/AR search

Access date: 2026-08-23

An official Dell interactive 3D service experience exists for PowerEdge R7525:

- Listing: https://www.dell.com/support/product-details/en-aw/product/poweredge-r7525/resources/3dguides
- Example experience: https://www.dell.com/support/resources/en-ie/3dviewer/ic1400r7525001909a/how-to-replace-the-rear-mounting-front-perc-module-on-a-poweredge-r7525

The public listing identifies the exact product, but direct real-browser access returned Akamai HTTP 403. No public direct GLB, glTF, OBJ, FBX, STEP, IGES, USDZ, or downloadable CAD URL could be retrieved without bypassing access controls. Dell's own community response to a 2025 request for an R7525 STEP file did not provide one: https://www.dell.com/community/en/conversations/rack-servers/3d-step-poweredge-r7525/67a84e2967c2593db3dbbb39

Therefore no official 3D binary is stored here. This record preserves the official viewer links and the access result; the standard and web GLBs in `../../model/` are independently constructed deliverables and are not claimed to be Dell CAD.
