# Dell PowerEdge R240 4LFF exterior GLB

Both GLBs are generated from the same exact exterior geometry. The standard file embeds the full-resolution six-face source lock; the web file uses proportion-preserving reduced copies. All six face materials are OPAQUE and all geometry transforms are positive.

- `Dell-R240-3.5inch.glb` — standard texture package.
- `Dell-R240-3.5inch-web.glb` — web texture package.
- `build-model.js` — deterministic self-contained GLB builder.

The model is an independent website exterior reconstruction, not engineering CAD. Its bottom is explicitly marked `GENERIC_BOTTOM_FALLBACK`; no unsupported underside holes, labels, feet, vents or seams are present.
