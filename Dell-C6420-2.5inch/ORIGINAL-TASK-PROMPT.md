三、官方尺寸与方向规范

1. 从 Dell 官方尺寸图和技术规格建立尺寸表，记录宽、高、深、节点尺寸，以及包含或不包含挂耳、把手、突出接口时的测量口径；每项附 URL、PDF 页码/图号和适用配置。
2. 区分官方数值、按比例估算值和假设值。不要从 AI 生成图读取尺寸；不要以通用“2U”“19 英寸”数值替代具体机身尺寸。官方表格与图示若有冲突或单位笔误，交叉验证并记录结论。
3. 固定坐标：X 为左右，Y 为前后，Z 向上；正面位于 -Y，背面 +Y，站在正面看服务器时右侧为 +X。模型以底面中心为基准，底面 Z=0。
4. Blender 内采用一致的公制比例，明确单位换算；推荐 1 Blender Unit = 1 米，官方毫米值除以 1000。导出后再次检查尺寸，避免重复换算。
5. 定义六个面的观察方向。背面照片的观察者左右关系与前视图不同，不能为了看起来一致而水平翻转。检查原始照片本身是否镜像，记录纠正依据；UV、文字、Logo 和非对称接口均须保持正确方向。

五、Blender MCP 与 computer use 协同建模

1. 使用参数化、可重复执行的 Blender Python 脚本，经 Blender MCP 实际执行并保存。先按官方尺寸建立主体，再逐步完成主要组件、细节、UV、材质和标识。
2. 建立真实立体结构，主要轮廓、挂耳、把手、托架、节点、电源和有深度的接口用合理几何表达；不要只做六张照片贴在长方体表面。
3. 孔洞与开口按真实结构处理，补足外壳厚度及必要的内部遮挡。真实通风口应保留通透关系；不应透视的位置不得因缺面或透明材质露出背面结构。内部只做到外观和开口观察所需，不虚构不可验证的精密组件。
4. 部件与材质清晰命名，按机箱/节点/面板/托架/接口/标识等组织。保留便于后续修改的组件关系，并记录面数、纹理尺寸和导出体积；在外观正确的前提下控制重复小结构的开销。
5. 文字和 Logo 使用独立、方向正确的 UV 或准确几何/贴花，不与有镜像变换的组件共享会反转文字的 UV。检查所有负缩放，合理应用变换并重算法线。
6. 金属与塑料材质默认不透明；颜色贴图不要误连 Alpha 或 Transmission。只有真实需要透明/镂空的部位采用对应材质，并验证导出后的 alpha 模式。Logo 贴花的透明仅用于标识背景，不应使机身透明。
7. 明确处理贴花、铭牌、孔网与基底之间的深度关系，避免共面或极近重叠面造成 Z-fighting。不要通过全局双面渲染掩盖反法线、缺面或错误透明。
8. 在主体、主要面板、标识材质、最终细节等阶段，实际使用 computer use 查看 Blender 窗口，点击/切换必要的视图并拖拽旋转观察。每次坐标操作前取最新截图，操作后验证结果；不能只用脚本设置相机和离线渲染就宣称已协同使用 computer use。
9. 保存阶段版本和检查截图，发现问题后实际修复。当前服务器使用 CPU 渲染与软件 OpenGL；此版 Blender 未带 OpenImageDenoiser，Cycles 中应关闭不支持的降噪。长渲染单独调度并监测，不让单次 MCP 调用一直超时，也不要因超时重复创建部件。

六、必须执行的质量检查

1. 尺寸：模型包围盒与已核实的官方尺寸核对，区分主体与突出部件，报告误差和估算项目。
2. 外观：六个面及四个斜视与同配置实拍并排比较，检查盘位、接口、把手、电源/节点布局、Logo 位置和比例。
3. 镜像：检查所有可读文字、Logo、非对称接口、UV、负缩放和导出坐标转换，不允许反字、反 Logo 或左右布局颠倒。
4. 几何：检查反法线、重复共面、退化面、意外内面、错误布尔结果、缺失厚度、不应开放的边界和明显穿插。不要把真实装配开口误判为必须封闭的孔。
5. 动态观察：通过 computer use 连续旋转模型至少一整圈，并检查多个俯仰角、近远距离、顶底视角和掠射角；同时保存转台视频或足以复核连续变化的图像序列。
6. 特别检查“改变角度时闪烁”以及“不该出现的透明导致穿模”：区分 Z-fighting、透明排序、背面剔除、裁剪面、细孔网摩尔纹和法线问题，修复根因，再复查受影响角度。不能只看一张正面图就判定通过。
7. 对比 Solid、Material Preview 和最终渲染。必要时使用浅色与深色背景检查 Alpha 问题，并调整合适的视口/相机 near/far clip。
8. 导出 GLB 后在独立场景或可用的 glTF 查看器中重新打开，复查真实尺寸、轴向、纹理、Logo、材质透明、法线和多角度显示。不能只验证原 .blend。
9. 每项检查记录通过/失败、证据文件、修复和复查结果。未解决问题必须如实列出，不得笼统宣称“全部无误”。
